# Confession enquiry & booking dashboard

A lightweight CRM for CONFESSION, 60 Marryatt Street, Port Adelaide.
See [docs/PLAN.md](docs/PLAN.md) for the full plan.

**Current phase: 2 (design preview with sample data).** Nothing is connected to
Supabase, HubSpot or Mailchimp yet.

## Running it on a computer
Needs [Node.js](https://nodejs.org) 20 or newer.

```
npm install
npm run dev            # opens a local copy at http://localhost:5173
npm test               # checks the report calculations
npm run build:preview  # makes the single-file preview in dist-preview/
```

A full README (keys, sync, deployment) comes in phase 7.
